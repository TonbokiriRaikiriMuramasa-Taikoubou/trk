# スキンの棚卸しと増量の計画

> 2026-10-08 作成。数は `js/` の定義を実際に読み込んで数えた結果（`SKINS` は `js/data.js` を評価、他はソースの定義を数えた）。アイデアの一覧は**案**であり、実装の決定ではない。

## 1. 数の定義（「スキン」と呼ぶもの）

「スキン」という言葉は、場所によって違うものを指していた。数を比べるときは、次の5種類を分けて数える。

| 種類 | 何を変えるか | 定義の場所 | 数 | 文書の旧表記 |
|---|---|---|---|---|
| ① ゲーム画面スキン | 譜面・背景の見た目（プレイ中の雰囲気） | `js/data.js` の `SKINS` | **27** | 「本体スキン」と書かれていた箇所はない |
| ② TVドックのスキン | テレビ本体の筐体（枠・形） | `js/tv-dock.js` の `TV_DOCK_SKINS` | **30** | `js/tv-dock.js` の冒頭に「本体のスキン30種」 |
| ③ 棚スキン | 曲タブの見た目（棚・カード・ノートなど） | `js/lib-skins.js` | **16** | 「棚スキン16種」（案内文・ガイド） |
| ④ 映像フィルター | テレビ映像の色・質感のプリセット | `js/tv-presets.js` の `TRK_TV_PRESETS` | **65** | 「映像フィルター65種」 |
| ⑤ 書斎の文字スキン | 本を読むページの色・書体・背景 | `js/study-room.js` の `studyTheme*`（見出し `studyThemeLabel` を除く） | **24** | 「24種」 |

**注意：**
- ①と②は ID が一つも重ならない。②の 30 を「本体スキン」と呼ぶと、①の 27 と混ざる。今後は上の表の名前（①〜⑤）で呼ぶ。
- 「本体スキン30種」は②（TVドック）のことで、ゲーム画面の数ではない。`js/tv-dock.js` の冒頭の文言は、次の変更で「TVドックのスキン30種」に直す。

## 2. 増やす対象の考え方

数だけを揃えるのではなく、**テーマの軸の偏り**を見て足す。現状の偏りは次の通り（目視で分類した概算）。

- **自然・季節・空**（夕焼け・夜明け・雪原・海・オーロラなど）：多い。
- **光・電子機器・サイバー**（ネオン・レーザー・ターミナル・ホログラムなど）：多い。
- **紙・文房具・手書き**（ノート・シール帳・クリアファイル・原稿用紙・和紙など）：ある程度ある。
- **生活の場面・日常の小物**（銭湯・窓辺・台所・駅・商店街など）：**少ない**。
- **和の質感・伝統の意匠**（墨・障子・提灯・風鈴など）：**少ない**。
- **音楽制作の道具**（楽譜・ミキサー・録音メーターなど）：**少ない**（ジュークボックス・レコード・カセットはあるが、制作の側の道具がない）。
- **ユーザー支援・見やすさ**（色覚にやさしい配色・大きな文字・低刺激）：**ない**。
- **ごく少数の「思いつきにくい」テーマ**（人が普段目にしない場所・道具・時間帯など）：**ない**。

## 4. 進め方

1. **一度に足す数は少なく**（1回に 3〜5 種類）。種類ごとに、設定・4言語・見た目の確認をそろえてから次へ進む。
2. **1種類ずつの作業**：
   - 定義を1項目足す（`SKINS`／`TV_DOCK_SKINS`／`lib-skins.js`／`TRK_TV_PRESETS`／`studyTheme*`）。
   - 名前・説明を**4言語（日・英・中・韓）**で同時に足す。
   - `npm run check` を通す。見やすさ（コントラスト）は、この作業で別途確かめる（既存の検査が見ているかは未確認）。
   - 追加の理由と権利の確認（素材・フォント・参考にしたもの）を HANDOFF に記録する。
3. **既存の検査**：`check-repo.mjs` などが、定義の形式と文言の欠落を見ているかを、最初の追加のときに確認して記録する。
4. **公開コードを変えたら** `sw.js` のキャッシュ名を上げる（HANDOFF §2.3）。
